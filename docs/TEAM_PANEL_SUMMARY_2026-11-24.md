## 1. 总体公式

### 1.1 攻击

```
攻击总值 = 白值(固定) × (1 + 攻击%/100) + 固定攻击
```

- **白值**：带武器裸面板里「加号前」的数值，是角色+武器的基础攻击；新加的武器/套装/共鸣链/奶妈攻击%只乘这个白值。
- **固定攻击**：带武器裸面板里「加号后」的部分，是技能树默认攻击%（12%/24%）已经折算出来的固定值；它不参与新百分比的乘法。
- 例：散华 `965 = 862 + 103` → 白值 862、固定 103；`862 × (1 + 80%) + 103 = 1654.6`。
- 零新百分比时：`白值 + 固定 = 你给的裸面板总值`（965/1300/1146/1133/1192/1269/1300）。

### 1.2 伤害（只用于排序）

```
E  = 攻击总值 × (1 + min(暴击,100)/100 × 暴伤/100) × (1 + 增伤/100)
排序分 = E × 循环系数(共效) × 稳定性系数(暴击)        ← 默认口径（2026-11-24 起）
```

- **增伤 = 属伤 + 专伤 + 通用**，直接相加；不再拆开算。
- 不计加深、抗性、防御。
- **默认乘共效循环系数**（共效 <120 线性打折，见 §6.4）；**暴击稳定性系数已关**（可无限重开，波折不构成成本）。
  `--no-gates` 两个都不乘（§6.5）；`--crit-gate` 可把暴击惩罚开回来。
- 暴击率按 100% 封顶。
- 4C 标准布局 **43311**（1×4C + 2×3C + 2×1C）；仇远 3+2 另算 **33311**（0×4C + 3×3C + 2×1C），
  但那只是为了回答「4C 只有暴击件」的问题，结论是**换 4C 主词条更好**（§6.6）。
- 3C 主属性只保留与角色同元素；异元素主属性不计。
- 4C 主属性默认用库存实物（暴击 22 / 暴伤 44 …）；`--swap4c` 可假设「同副词条、主词条换暴伤」（§6.6）。

### 6.4 门槛系数：共效保留、暴击关闭

```
系数 = max(最低, 1 − 斜率 × (目标 − 值) / 目标)        值 ≥ 目标 → 1.0（只减不增）
共效：目标 120 / 斜率 0.30 / 最低 0.85          ← 保留
暴击：目标 100 / 斜率 0.40 / 最低 0.80          ← 2026-11-24 关闭
```

**共效为什么留**：共效不足直接影响循环（能不能按轴放技能），是真实约束，不是统计噪声；
它也不进期望伤害公式，所以不算重复计权。

**暴击为什么关**：

1. `E = 1 + p×cd` 已经是期望值，"15% 不暴击"这件事已经算在里面了。再乘一个按 p 的惩罚，
   等于把暴击率计两次 —— 数学上不是重复计算同一项，但 E 就不再是期望，而是「期望 × 风险折价」。
2. **它没在测波动率**：波动率是 `√(p(1−p))·cd / (1+p·cd)`，跟暴伤也有关，而门槛只看暴击率。
   实测两套波动几乎一样的配装（85% 暴击 + 100% 暴伤 的 CV 19.3%；91.8% + 207.6% 的 CV 19.6%），
   门槛扣分是 6.0% vs 3.3%。
3. **扣分幅度和真实波动不匹配**：一轮 30 段打下来，总伤害的每轮波动只有 2~6.6%（CV/√N），
   门槛却直接扣掉均值 6~9.6%。
4. **无限重开**：挑战可以反复重打，一次没暴击就重来，波动不构成成本 —— 期望值就是最优目标。

保留 `--crit-gate` 可以把它开回来做敏感性；默认关。

### 10.2 口径的三次调整（重要，别再用旧数）

| 阶段 | 口径 | 触发 |
|---|---|---|
| 上午（§1~§7 原文） | 纯伤害，不乘任何系数 | 当时没给循环要求 |
| 下午一 | 共效 + 暴击门槛系数**都开** | 「默认以带系数的最优口径，更贴近现实」 |
| 下午二（**现行**） | **只留共效系数，暴击稳定性系数关** | 「可以无限重开挑战」→ 波折不构成成本；且暴击率会被计两次、该系数并不测波动率（论证见 §6.4） |

现行定义：`E = 期望伤害 × 共效系数`。共效 <120 才打折，所以 9 个方案里只有 4 套被轻微调整。

### 10.4 新增的两个「假设件」分析

| 开关 | 假设 | 用途 |
|---|---|---|
| `--swap4c` | 每只 4C 追加一个「主词条 = 暴伤 44」的副本（副词条/等级不动，同名） | 比较 4C 主属性选暴击还是暴伤 |
| `--swap3c key,…` | 指定方案的 3C「属伤 30」主词条换成「攻击% 30」（同副词条） | 比较 3C 主属性选属伤还是攻击% |

副本与原件同名同套装，所以同一只只会在组合里出现一个版本，不会「暴击版和暴伤版一起上」。
`--swap3c` 必须指定方案 key，否则所有角色都会看到这批假件。

### 10.5 可直接引用的结论

1. **33311 只是「4C 只有暴击件」的替代品**：现库存下 43311 40916.0 / 33311 41265.2（+0.85%）；
   把 4C 主词条换成暴伤后 43311 变 **43561.2**，比现库存高 **+6.46%**、比 33311 高 **+5.56%**。
   → 该换的是 4C 主词条，不是把 4C 拿掉。
2. **西格莉卡 3C 换攻击%**：3+2 +0.91%、5 件套 +0.18%。之所以能涨，是因为她的增伤池已到 265
   （30 点属伤只值 +8.2%），而 30% 攻击乘 1024 白值 = +307 攻击（+9.9%）。**<1%，不值得专门换件**。
3. **门槛系数对结论的影响**：暴击惩罚在时 3+2 领先 5.51%；关掉后 **5.13%**。那 0.4pp 是惩罚造成的，不是真实差距。
4. **评分和最高 ≠ 伤害最优**：达妮娅差 22.28%、仇远 5 件套 16.74%、仇远 3+2 15.68%、散华 7.42%、
   绯雪 5.47%、陆赫斯 1.52%、爱弥斯 2.46%；只有西格莉卡两者是同一套（0%）。
5. **各方案最优 E（43311）**：散华 18407.5 / 陆赫斯 28154.7 / 达妮娅 23555.2 / 爱弥斯 34505.4 /
   仇远 3+2 40916.0 / 仇远 5 34381.5 / 西格莉卡 3+2 40665.7 / 西格莉卡 5 43218.9 / 绯雪 28943.5。

### 10.6 复现命令

```bash
# 一条命令全量重建（推荐）
python tools/analysis/build_team_panel.py --py-data <有 cv2 的解释器> --py-xlsx <有 openpyxl 的解释器>

# 只重出工作簿 / 只检查环境 / 账本写数值不写公式
python tools/analysis/build_team_panel.py --skip-data ...
python tools/analysis/build_team_panel.py --check ...
python tools/analysis/build_team_panel.py --values-only ...
```

等价的展开版（driver 内部就是跑这些）：

```bash
python tools/analysis/team_plan.py            --out logs/analysis/team_plan_20261124
python tools/analysis/team_plan.py --no-gates --out logs/analysis/team_plan_20261124/pure
python tools/analysis/team_plan.py --swap4c   --out logs/analysis/team_plan_20261124/swap4c
python tools/analysis/team_plan.py --swap3c sigrika32,sigrika5 --out logs/analysis/team_plan_20261124/swap3c
python tools/analysis/team_panel_xlsx.py
python tools/analysis/team_plan_xlsx.py logs/analysis/team_plan_20261124/team_plan.json \
    logs/analysis/team_plan_20261124/team_plan.xlsx
```

**两个解释器**：`team_plan.py` 依赖 `cv2`（主 requirements.txt）；`*_xlsx.py` 依赖 `openpyxl`
（`tools/analysis/requirements.txt`）。driver 会自动探测并通过 `--py-data/--py-xlsx` 指定，
混用会 ModuleNotFoundError。

**重算**：openpyxl 写的公式不带缓存值 —— 用 Excel/WPS/LibreOffice 打开一次即重算；
给不支持重算的查看器用时加 `--values-only`（直接写算好的数）。
