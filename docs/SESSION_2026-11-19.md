## 2. 面板滚动：判据换了三版

| 版本 | 判据 | 为什么错 |
|---|---|---|
| v1 | 名字行可见 | **恒为真**（固定表头）→ 从未真正回顶 |
| v2 | 上滚后"内容不再移动"，但一次大回滚 + 固定步数 | 仍按"滚了多少格"给距离；长面板（80 格）不够 |
| **v3（当前）** | **滚一下 → 等动画停稳 → 比帧；连续两次没变化 = 到顶/到底** | 与步长/格数/布局全部无关 |

配套的两条纪律（都是真机踩出来的）：

- **先等停稳，再比帧**：面板是 ease-in 动画，滚完 0.20s 就比帧会一直判"还在动"（17:00 那 5 次假失败就是这么来的）。
  停稳判据与网格一致：相邻两帧差异 < 2% 连续两次。
- **步长只是"少滚几次"**：回顶 `8→16→32→64` 翻倍（长面板也够），找套装 `8/4` 小步（大步会跨过目标文本）；
  `SET_PANEL_MAX_STEPS` 退化成纯安全阀（24 次）。

## 4. 套装：#95 的教训（面板文字 > 名字候选）

```
17:05:53 [套装] 合鸣效果区读到套装名: 息界同调之律(text/all, 滚 16 格)
17:05:57 [评估#95] 梦魔·咕咕河豚 … 套装=凝夜白霜(name)     ← 面板白读了
```

`_match_echo_key` 把 `梦魔` 当噪声剥掉 → 落到 `咕咕河豚`（2 套候选）；面板上写的 `息界同调之律` 因为
"不在候选内"被 `resolve_set_name` 丢掉，退回候选首个。**候选是"按 OCR 名字推的"，名字读错时候选本身就是错的**。

规则改为：

```
面板明写的套装名(text)      → 一律采信（名字候选只用来决定"要不要去滚面板"）
效果原文覆盖率(effect)      → 仍然要求落在候选内（这是模糊信号）
```

## 5. COST：角标 → 主属性反推为主，角标佐证

| 信号 | 角色 | 依据 |
