## 1. 最值得记的一条：探针自己有个 bug

`docs/UI_FIX_HANDOFF.md` 承诺"修完 B1 应 5/5"，但 **C3/C4 永远 FAIL**，无论代码怎么改：

```python
nxt = re.search(r'^\s*def ', src[start + 1:], re.M)   # ← 从"行首+1"切片
```

新串的第 0 个字符就是行首，`^` 在字符串开头直接匹配，`\s*` 吃掉剩下 3 个缩进、`def ` 命中**函数自己**
→ `_function_body()` 返回长度 1 的残片。于是两项静态检查恒假。

修法不只是修正则——**把这两项从"grep 源码"改成"跑真代码"**：喂一个假 task 给 `status_texts`、
喂 10 条假记录给 `summary_text`，看输出对不对。静态 grep 也分不清"读了正确的键"和"读了别的键"。

顺带把纯展示逻辑抽到**零依赖**的 `ui/present.py`：`ui/run_tab.py` 顶部 `from ww_engine import og`，
而"进程里 import 过 ww_engine + `show()` 过 Fluent 顶层窗口"在**解释器退出时段错误 0xC0000005**
（实测 6 次里 4 次）—— 探针为了跑真代码被迫把引擎拖进来就中招。

## 2. 四批做了什么（细节见 CHANGELOG 补记 74~77）

### B1 — 5 个 P0（`168c28e`，单测 360 → 378，探针 0/5 → 5/5）
SpinBox 数值可见 / 两页可滚 / 评估计数 / 六档汇总 / 判定配色。
**工单的 5 行子类不够**：`RIGHT_RESERVED=74` 会让文字钻到按钮底下 6px；而且"编辑区 ≥20px"≠读得出数值 ——
两个 31px 按钮吃掉 71px，控件 < ~105px 时 `0.10` 显示成 `0.1C`。已改为问布局要预留量 + 把 6 个过窄控件加宽到 124，
验收口径升级成"**放得下当前文本 + 4px**"。

### B2 — 运行页/导航/穷举/表格/文案（`0d402e4`，378 → 384）
**日志必须常驻**：改成固定状态卡 + 左右双栏后，日志在 1120×760 下 27 行、892×570 下 11 行（原来 70px 或完全不可见）。
两个连带坑：左栏只有 ~360px → 5 张任务卡换 `WrapSettingCard`；**日志工具条横排时最小宽 586px，会把整页撑到 942**
（940 窗口的内容区只有 750）→ 改流式行后整页最小宽 546。
导航 `minimumExpandWidth` 库默认 **1008 > 本窗口最小 940** → 展开会被 `resizeEvent` 立刻收回，且 `expand()`
必须在 `_init_geometry()` **之后**调（它按当前宽度决定真展开还是弹浮层）。

### B3 — 报告（`3e61d78`，384 → 406）
行折叠 + 判定 chip（含色弱符号）+ 筛选写进 hash + `@media print` + 规则文案重写。
**JS 的三个坑**：①筛选/排序**只能遍历 `tr.main`**（旧写法 `querySelectorAll('#tbody tr')` 会把详情行当数据行）；
②排序搬主行前**先取**配对详情行（`appendChild` 之后 `nextElementSibling` 就变了）；
③详情可见性 = 主行可见 **且** 已展开。
依赖说明从页脚挪到**页首** —— 页脚在 160 行表格最底下，没人看得到。
顺手修掉报告正文里的 `**单文件**`（HTML 不认 Markdown，会原样显示星号），并加了单测。

### B4 — 打磨（`a0a385b`，406 → 411）
标题层级（状态卡改 `SimpleCardWidget`，一页只留一个标题，顺带省 48px）/ 提示条位置 /
关于页（数据版本 `3.7.0 · 37 套 / 229 声骸` + 诊断入口）/ 代码框等宽 / 深色画布 `#0F1315`。

## 4. 踩过的坑（下次别再踩）

1. **别按 `widget.fontMetrics()` 算表格列宽** —— qfluentwidgets 的 `TableItemDelegate` 把每格字体强制成
   `getFont(13)`，QSS 还有左右各 16px 内边距 → 可用文本宽 ≈ 列宽 − 44。
2. **给 QTextEdit/QPlainTextEdit 设控件级样式表要带 `background:transparent`** —— 否则盖掉主题底，深色变白底浅字。
3. **`QStackedWidget` 按最高子页预留高度** —— 调试页的「截图」页预览图 min 200 会把 OCR 页也撑到 419。
4. **`expand()` 在构造期调会退化成浮层** —— 那时窗口还没定尺寸。
5. **离屏建 QApplication + `show()` Fluent 窗口 + 进程里 import 过 ww_engine → 退出时段错误**；
   `deleteLater()` + `processEvents()` 走 Qt 自己的销毁路径即可（探针/工具/测试都这么收尾）。
6. **`QApplication` 要挂在模块级** —— 放局部变量里，销毁时机落到解释器退出期，与仍存活的窗口抢顺序。
7. **报告 JS 改动必须跑浏览器验** —— 单测只能断言"字符串里有这段 JS"；一次 `syncDetail` 漏写就会留下孤儿详情行。
