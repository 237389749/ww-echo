## 3. 关键决定（本会话已定）

1. **通用共效 0.6→0.5**：依据参考工程 linear 爱弥斯 0.40、Wuwa 中位 0.35；用户拍板 **0.5**，不是 0.4~0.45。
2. **通用 B 仍固定 17.5**：`_GENERAL_WEIGHTS` 改为固定策略档位 `(1.0,0.7,0.6,0.5,0.4,0.25)`。
   若继续用 `DEFAULT_WEIGHTS` 去重自动推导，0.5 与攻击%合并后档位变少，B(5) 会从 17.5 抬到 18.5
   （等于顺手收紧保留线）；这不作为权重调整的副作用。以后要改 B 需显式决定。
3. **不引入 Rust**：参考项目的 Rust 核心是精确策略 DP/服务端/Tauri；我们当前瓶颈是 OCR/游戏 IO，
   `reforge_plan` 仅 ~190ms，numpy 向量化就够；Rust 只在将来做“期望成本 DP”时作为可选求解器后端。
4. **不修改强化/重铸阈值、不引入主属性进评分**：P1（强化 0.60 门槛拆分）与 P2（主属性）仍需用户拍板。
5. **`og`/`communicate` 保留**：它们是运行时服务定位，不是 import 环；domain 已不碰 `og`。
