# Helios
**Universal** Client Patch for Wuthering Waves.

## How to
1. Compile (or get a prebuilt of) `helios.dll` and `helios_launcher.exe`, and put them into [Game Directory]/Client/Binaries/Win64.
2. Grab the latest pak file patch from [here](https://git.xeondev.com/RabbyDevs/zigrika-pakfile/releases) and put it into [Game Directory]/Client/Content/Paks
3. After that, use `helios_launcher.exe` (as admin) to launch the game.
4. You'll see the Kuro debug login pop-up. Enter any username in the center textbox. 
5. Input the login server's IP (default is http://127.0.0.1:10001) in the textbox on the top left (a little to the right, after the dropdown).

Make sure the server's IP does not contain an extra / at the end.
